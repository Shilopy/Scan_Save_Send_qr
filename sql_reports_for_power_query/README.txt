=== ИНСТРУКЦИЯ ДЛЯ POWER QUERY (Excel / Power BI) ===

=== Подключение к PostgreSQL ===

1. Excel: Данные -> Получить данные -> Из базы данных -> Из базы данных PostgreSQL
   Power BI: Получить данные -> База данных PostgreSQL

2. Заполните параметры:
   - Сервер: localhost (или ваш сервер БД)
   - База данных: chz_cises

3. В окне навигации НЕ выбирайте таблицу — нажмите "Дополнительно"

4. В поле "Инструкция SQL" (SQL statement) вставьте содержимое
   нужного SQL-файла из этой папки

5. Нажмите OK

=== Если не видите кнопку "Дополнительно" ===

Вместо шагов 3-4:
- Выберите любую таблицу и нажмите "Загрузить"
- В Excel: откройте Power Query Editor
- В панели слева выберите запрос
- В строке формул (или в Advanced Editor) замените текст на нужный SQL
- Либо: Данные -> Получить данные -> Из других источников ->
  Пустой запрос -> Advanced Editor -> вставьте SQL

=== Если не работает встроенный коннектор PostgreSQL ===

1. Скачайте и установите ODBC драйвер PostgreSQL:
   https://www.postgresql.org/ftp/odbc/versions/msi/

2. Excel: Данные -> Получить данные -> Из других источников ->
   Из ODBC -> выберите "PostgreSQL35W"

3. Вставьте SQL-запрос

=== ПРИМЕР ДЛЯ POWER QUERY (прямой M-код) ===

Если SQL не проходит, используйте этот M-код (откройте Advanced Editor):

let
    Source = PostgreSQL.Database("localhost", "chz_cises"),
    CustomSQL = Value.NativeQuery(
        Source,
        "<сюда вставьте SQL-запрос из файла>",
        null,
        [EnableFolding=true]
    )
in
    CustomSQL

=== ФИЛЬТРАЦИЯ ПО ПЕРИОДУ ===

Если нужно посчитать ТОЛЬКО коды, эмитированные в определенном периоде:
В любой SQL-запрос добавьте в конец (перед GROUP BY если есть):
    AND emission_date::date BETWEEN '2026-01-01' AND '2026-06-30'
Где 2026-01-01 и 2026-06-30 замените на свои даты.
