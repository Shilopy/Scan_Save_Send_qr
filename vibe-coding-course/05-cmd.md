## Полный справочник CMD

### Навигация

| Команда | Что делает | Пример |
|---------|-----------|--------|
| `dir` | Показать файлы в текущей папке | `dir` |
| `cd папка` | Зайти в папку | `cd supply_manager` |
| `cd ..` | Подняться на уровень выше | `cd ..` |
| `cd \` | Перейти в корень диска C: | `cd \` |
| `tree` | Показать дерево папок | `tree` |
| `cls` | Очистить экран | `cls` |

### Работа с файлами и папками

| Команда | Что делает | Пример |
|---------|-----------|--------|
| `mkdir имя` | Создать папку | `mkdir new_folder` |
| `rmdir имя` | Удалить ПУСТУЮ папку | `rmdir old_folder` |
| `rmdir /s имя` | Удалить папку со всем содержимым | `rmdir /s old_folder` |
| `del файл` | Удалить файл | `del temp.py` |
| `copy a b` | Скопировать a в b | `copy main.py backup.py` |
| `ren a b` | Переименовать a в b | `ren old.py new.py` |
| `type файл` | Показать содержимое файла | `type main.py` |

### Python

| Команда | Что делает | Пример |
|---------|-----------|--------|
| `python file.py` | Запустить Python файл | `python main.py` |
| `python` | Открыть Python в интерактивном режиме (выйти: exit()) | `python` |
| `pip install пакет` | Установить библиотеку | `pip install pandas` |
| `pip list` | Показать установленные библиотеки | `pip list` |
| `pip freeze` | Показать библиотеки в формате для requirements.txt | `pip freeze` |
| `pip freeze > requirements.txt` | Сохранить список в файл | `pip freeze > requirements.txt` |
| `pip install -r requirements.txt` | Установить всё из файла | `pip install -r requirements.txt` |

### Виртуальное окружение

| Команда | Что делает |
|---------|-----------|
| `python -m venv venv` | Создать виртуальное окружение |
| `venv\Scripts\activate` | Активировать (Windows) |
| `deactivate` | Деактивировать |

### Полезные трюки

| Действие | Что происходит |
|----------|---------------|
| Стрелка `вверх` | Показать предыдущую команду |
| `Ctrl+C` | Остановить выполняющуюся программу |
| `Ctrl+Shift+V` | Вставить текст в CMD |
| Выделить текст + Enter | Скопировать выделенное |
| `cd drag-and-drop папки` | Вставить путь к папке (просто перетащи папку в CMD) |

## Как читать ошибки (traceback)

Пример ошибки:
```
Traceback (most recent call last):
  File "C:\Users\user\Desktop\supply_manager\main.py", line 5, in <module>
    print(1/0)
ZeroDivisionError: division by zero
```

**Как читать:**
1. **Последняя строка** — тип ошибки и короткое описание:
   - `ZeroDivisionError` — деление на ноль
   - `FileNotFoundError` — файл не найден
   - `NameError` — имя не определено (опечатка)
   - `TypeError` — неверный тип данных
   - `ValueError` — неверное значение
   - `SyntaxError` — синтаксическая ошибка
   - `ModuleNotFoundError` — библиотека не установлена
   - `ImportError` — не удалось импортировать

2. **Третья строка снизу** — где произошла ошибка:
   - Файл: `main.py`
   - Строка: `line 5`
   - Что делал: `print(1/0)`

## Практика: намеренно сломай код

Чтобы научиться читать ошибки, сломай код специально:

1. Открой `hello.py`
2. Удали одну кавычку — запусти, посмотри `SyntaxError`
3. Напиши `prrint()` вместо `print()` — запусти, посмотри `NameError`
4. Напиши `print(1/0)` — посмотри `ZeroDivisionError`

В каждом случае:
- Скопируй ошибку
- Отправь Cline: "Вот ошибка, исправь"
- Посмотри что изменилось

## .bat файлы для быстрого запуска

Создай файл `run.bat` в папке проекта (через Cline):

**Промпт для Cline:**
```
Создай файл run.bat в корне проекта supply_manager.
Он должен:
1. Активировать виртуальное окружение venv\Scripts\activate
2. Запускать main.py
3. Если ошибка — показать её и подождать нажатия клавиши
```

Теперь проект запускается двойным кликом по `run.bat`.
