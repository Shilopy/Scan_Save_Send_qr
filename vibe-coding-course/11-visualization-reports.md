## Шаг 1: Обзор библиотек

| Библиотека | Для чего |
|-----------|---------|
| **matplotlib** | Базовые графики (линии, столбцы, круги) |
| **pandas** | Встроенные графики через DataFrame.plot() |
| **openpyxl** | Создание Excel-файлов с форматированием |
| **streamlit** | Веб-дашборды за 15 минут |

## Шаг 2: График продаж по месяцам

**Промпт для Cline:**
```
В проекте supply_manager создай файл reports.py.

Напиши функцию plot_monthly_sales():
1. Подключается к БД supply_db
2. Выполняет запрос:
   SELECT DATE_TRUNC('month', purchase_date) as month, SUM(total_cost) as total
   FROM purchases
   GROUP BY month
   ORDER BY month
3. Строит столбчатую диаграмму через matplotlib:
   - Ось X: месяцы
   - Ось Y: сумма закупок
   - Заголовок: "Ежемесячные закупки"
4. Сохраняет как monthly_sales.png
```

## Шаг 3: Круговая диаграмма — доли поставщиков

**Промпт для Cline:**
```
В reports.py добавь функцию plot_supplier_pie():
1. Запрос: по каждому поставщику общая сумма закупок
   SELECT s.name, SUM(p.total_cost) as total
   FROM purchases p
   JOIN suppliers s ON p.supplier_id = s.id
   GROUP BY s.name
   ORDER BY total DESC
2. Строит круговую диаграмму (pie chart):
   - Подписи: названия поставщиков
   - Доли: процент от общей суммы
   - Заголовок: "Распределение закупок по поставщикам"
3. Сохраняет как supplier_pie.png
```

## Шаг 4: Автоматический Excel-отчёт с форматированием

**Промпт для Cline:**
```
В reports.py добавь функцию create_excel_report():
1. Создаёт Excel-файл supply_report.xlsx с тремя листами:

   Лист 1: "Закупки по месяцам"
   - Данные из plot_monthly_sales (месяц | сумма)
   - Жирный заголовок, авто-ширина колонок

   Лист 2: "Топ-10 материалов"
   - Запрос: SELECT m.name, SUM(p.total_cost) as total
     FROM purchases p JOIN materials m ON p.material_id = m.id
     GROUP BY m.name ORDER BY total DESC LIMIT 10

   Лист 3: "Статистика по поставщикам"
   - Имя, количество закупок, сумма, средний чек

2. Использует openpyxl для форматирования:
   - Заголовки жирным
   - Числовые форматы (#,##0.00)
   - Авто-ширина колонок
3. Сохраняет как supply_report.xlsx
```

## Шаг 5: Streamlit-дашборд (веб-интерфейс)

**Промпт для Cline:**
```
В проекте supply_manager создай файл dashboard.py.

Напиши Streamlit-дашборд с:
1. Заголовок: "Supply Manager - Дашборд закупок"
2. Метрики (st.metric):
   - Всего поставщиков (счётчик из БД)
   - Всего материалов
   - Общая сумма закупок
3. График ежемесячных закупок (из reports)
4. Таблица последних 10 закупок
5. Селектор выбора поставщика:
   - При выборе показывает историю закупок этого поставщика

Используй st.columns для расположения метрик в ряд.
```

Установи: `pip install streamlit`
Запуск: `streamlit run dashboard.py`
