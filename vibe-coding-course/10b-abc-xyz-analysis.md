# Проект Б: ABC-XYZ анализ запасов

**Время**: 1 час
**Цель**: научиться категоризировать запасы для оптимизации управления

---

## Бизнес-контекст

Не все материалы одинаково важны. Некоторые дорогие, некоторые дёшевые. На некоторые спрос стабильный, на другие — скачкообразный.

**ABC-анализ** делит материалы по стоимости:
- **A** — 80% затрат (немного товаров, много денег)
- **B** — 15% затрат
- **C** — 5% затрат (много товаров, мало денег)

**XYZ-анализ** делит по стабильности спроса:
- **X** — стабильный спрос (можно закупать равномерно)
- **Y** — средняя стабильность
- **Z** — нестабильный спрос (нужен страховой запас)

## Шаг 1: ABC-анализ

**Промпт для Cline:**
```
В проекте supply_manager создай файл abc_xyz.py.

Напиши функцию abc_analysis():
1. Подключается к БД supply_db
2. Выполняет запрос: для каждого материала посчитать общую сумму закупок
   SELECT m.name, SUM(p.total_cost) as total_spent
   FROM purchases p
   JOIN materials m ON p.material_id = m.id
   GROUP BY m.name
   ORDER BY total_spent DESC
3. Сортирует по убыванию суммы
4. Считает накопительный процент от общей суммы
5. Присваивает категорию:
   - A: первые 80%
   - B: следующие 15%
   - C: последние 5%
6. Выводит таблицу: Материал | Сумма | Доля % | Категория
```

## Шаг 2: XYZ-анализ

**Промпт для Cline:**
```
В abc_xyz.py добавь функцию xyz_analysis():
1. Подключается к БД supply_db
2. Выполняет запрос: продажи по материалам за последние 6 месяцев по месяцам
   SELECT m.name, DATE_TRUNC('month', sh.sale_date) as month, SUM(sh.quantity_sold) as total
   FROM sales_history sh
   JOIN materials m ON sh.material_id = m.id
   WHERE sh.sale_date >= NOW() - INTERVAL '6 months'
   GROUP BY m.name, month
   ORDER BY m.name, month
3. Для каждого материала считает коэффициент вариации (CV = std/mean)
4. Присваивает категорию:
   - X: CV < 0.5 (стабильный)
   - Y: 0.5 <= CV < 1.0 (средний)
   - Z: CV >= 1.0 (нестабильный)
5. Выводит таблицу: Материал | Среднее | Стандартное отклонение | CV | Категория
```

## Шаг 3: Матрица ABC-XYZ

**Промпт для Cline:**
```
В abc_xyz.py добавь функцию abc_xyz_matrix():
1. Вызывает abc_analysis() и xyz_analysis()
2. Объединяет результаты в единую таблицу
3. Выводит матрицу 3x3:

         | X (стабильный) | Y (средний) | Z (нестабильный)
---------|----------------|-------------|------------------
A (дорогие) |    A-X     |    A-Y     |    A-Z
B (средние) |    B-X     |    B-Y     |    B-Z
C (дёшевые) |    C-X     |    C-Y     |    C-Z

4. Для каждой ячейки выводит список материалов
```

## Шаг 4: Рекомендации по управлению

**Промпт для Cline:**
```
В abc_xyz.py добавь функцию recommendations():
1. Анализирует матрицу ABC-XYZ
2. Выводит рекомендации для каждой группы:

Группа   | Стратегия закупок
---------|------------------
A-X      | Минимальный запас, точно в срок (JIT)
A-Y      | Чуть больше запаса, прогнозирование
A-Z      | Страховой запас, поиск альтернатив
B-X      | Стандартный заказ раз в месяц
B-Y      | Умеренный запас
B-Z      | Повышенный страховой запас
C-X      | Заказ большими партиями
C-Y      | Заказ по накоплению
C-Z      | Минимальные закупки под заказ

3. Выводит в main() при запуске
```
