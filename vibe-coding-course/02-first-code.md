## Задание 1: Привет, мир!

**Промпт для Cline:**
```
Напиши простой Python скрипт.
1. Спроси у пользователя его имя (используй input())
2. Поприветствуй его: "Привет, {имя}!"
3. Спроси, сколько ему лет
4. Скажи: "Через 10 лет тебе будет {возраст + 10}"
Сохрани в файл hello.py
```

**Что происходит:**
- Cline создаёт файл `hello.py`
- Ты открываешь файл в VS Code (он появится слева в списке файлов)
- Читаешь код — понимаешь каждую строку

**Запуск:**
1. Открой CMD
2. Перейди в папку проекта: `cd Desktop\my_first_project`
3. Запусти: `python hello.py`
4. Введи имя и возраст

**Разбор ошибок:**
- `SyntaxError` — опечатка в коде, покажи Cline, он исправит
- `FileNotFoundError` — не тот путь, проверь где файл
- `IndentationError` — проблемы с отступами

## Как читать код (алгоритм для новичка)

1. Смотри **сверху вниз**: код выполняется построчно
2. Ищи `input()` — это места, где программа ждёт твоего ввода
3. Ищи `print()` — это то, что программа выводит
4. Ищи `=` — это присваивание (сохраняем значение в переменную)
5. Ищи `if/else` — это условия (выбор варианта)

## Что делать если код не работает

1. **Скопируй ошибку** (весь красный текст из CMD)
2. **Вставь в Cline** со словами: "Вот ошибка, исправь"
3. **Дождись исправления**
4. **Запусти снова**
