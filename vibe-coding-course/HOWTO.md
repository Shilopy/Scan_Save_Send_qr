## 2. Как открыть курс на своём компьютере

**Шаг 1.** Если VS Code не установлен — скачай с [code.visualstudio.com](https://code.visualstudio.com) и установи.

**Шаг 2.** Перенеси папку `vibe-coding-course` на свой рабочий стол.

**Шаг 3.** Открой VS Code:
   - Нажми **File** -> **Open Folder**
   - Найди папку `vibe-coding-course` на рабочем столе
   - Выбери её и нажми **Select Folder**

**Шаг 4.** Слева увидишь список файлов. Нажми на `README.md` — он откроется.

**Шаг 5.** VS Code умеет показывать .md файлы красиво:
   - Нажми `Ctrl+Shift+V` — откроется **предпросмотр** (красивое форматирование)
   - Или нажми правой кнопкой по вкладке -> **Open Preview**

Теперь ты можешь читать модули и сразу копировать промпты в Cline.

## 4. Алгоритм прохождения ОДНОГО модуля (делай это каждый раз)

```
ШАГ 1: Открой файл модуля (например 02-first-code.md)
       -> читаешь в VS Code, нажав Ctrl+Shift+V для красивого вида

ШАГ 2: Прочитай "Цель" и "Время"
       -> пойми, сколько времени нужно выделить

ШАГ 3: Найди блок "Промпт для Cline"
       -> он выглядит как серый блок текста

ШАГ 4: Скопируй текст промпта (Ctrl+C)
       -> выдели весь текст внутри серого блока

ШАГ 5: Открой Cline в VS Code
       -> иконка Cline в левой панели (или Ctrl+Shift+I)

ШАГ 6: Вставь промпт в чат Cline (Ctrl+V)
       -> текст появится в поле ввода

ШАГ 7: Нажми Enter
       -> Cline начнёт писать код, создавать файлы

ШАГ 8: Дождись пока Cline закончит
       -> он покажет что сделал

ШАГ 9: Прочитай код
       -> открой созданный файл и прочитай каждую строку
       -> если не понимаешь — спроси Cline: "Объясни этот код"

ШАГ 10: Запусти код
        -> открой CMD (Win+R -> cmd -> Enter)
        -> перейди в папку: cd Desktop\supply_manager
        -> активируй venv: venv\Scripts\activate
        -> запусти: python main.py (или python имя_файла.py)

ШАГ 11: Если ошибка — не паникуй
        -> скопируй красный текст из CMD
        -> вставь в Cline: "Вот ошибка, исправь"
        -> дождись исправления, запусти снова

ШАГ 12: Если код работает — отметь пункты в чек-листе
        -> поставь X в квадратных скобках: [X]

ШАГ 13: Сделай git commit
        -> скажи Cline: "Сделай git add . и git commit"
        -> или сам: git add . && git commit -m "Модуль 2 пройден"

ШАГ 14: Переходи к следующему модулю
```

## 5. Что такое "Промпт для Cline"

**Промпт** — это текст, который ты отправляешь ИИ (Cline), чтобы он написал код.

В модулях промпты выглядят так:

```
Ты Python-разработчик. Напиши скрипт, который:
1. Спрашивает имя пользователя
2. Выводит "Привет, {имя}!"
Сохрани в файл hello.py
```

**Важно:** копируй ВЕСЬ промпт целиком. Не добавляй и не убирай слова — так Cline сделает именно то, что задумано в уроке.

## 7. Сквозной проект supply_manager

Начиная с **Модуля 3**, ты работаешь в одной папке — `supply_manager`.

Это **сквозной проект**: каждый новый модуль добавляет в него новый функционал.

**ВАЖНЫЕ ПРАВИЛА:**
1. **Не удаляй папку `supply_manager`** между модулями
2. **Не удаляй файлы** из неё (каждый файл нужен в следующих модулях)
3. **Не пересоздавай проект** — ты его улучшаешь, а не создаёшь заново
4. **Делай git commit** после каждого модуля — чтобы можно было откатиться

Структура проекта после прохождения всех модулей:

```
supply_manager/
├── main.py                <- точка входа (меню)
├── utils.py               <- вспомогательные функции
├── config.py              <- настройки + .env
├── queries.py             <- SQL-запросы
├── forecast.py            <- прогнозирование спроса
├── abc_xyz.py             <- ABC-XYZ анализ
├── mrp.py                 <- MRP расчёт
├── suppliers_module.py    <- управление поставщиками
├── reports.py             <- графики и отчёты
├── dashboard.py           <- Streamlit-дашборд
├── requirements.txt       <- библиотеки
├── .env                   <- пароль от БД (секретно!)
├── .gitignore
├── README.md
├── tests/                 <- тесты
│   └── test_mrp.py
├── update_prices.xlsx     <- пример прайс-листа

├── forecast_chart.png     <- график прогноза
└── run.bat                <- быстрый запуск
```

## 8. Что делать с ошибками (пошаговый алгоритм)

```
┌─ Возникла ошибка ─────────────────────────────┐
│                                                │
│  1. НЕ ПАНИКУЮ                                  │
│  2. Читаю последнюю строку ошибки               │
│     (там написано: NameError, SyntaxError и т.д.)│
│  3. Копирую ВЕСЬ красный текст из CMD (Ctrl+A)  │
│  4. Вставляю в Cline:                           │
│     "Вот ошибка, исправь:"                      │
│     [вставленный текст ошибки]                   │
│  5. Жду пока Cline исправит                      │
│  6. Запускаю снова                               │
│  7. Если опять ошибка — повторяю шаг 3-6        │
│                                                │
└────────────────────────────────────────────────┘
```

**Частые ошибки и их решение:**

| Ошибка | Что значит | Что делать |
|--------|-----------|-----------|
| `ModuleNotFoundError: No module named 'pandas'` | Библиотека не установлена | `pip install pandas` |
| `FileNotFoundError` | Файл не найден | Проверь что ты в правильной папке (cd) |
| `SyntaxError` | Опечатка в коде | Покажи Cline, он исправит |
| `NameError: name 'x' is not defined` | Переменная не объявлена | Покажи Cline |
| `psycopg2.OperationalError` | Нет подключения к БД | Проверь что PostgreSQL запущен и пароль правильный |
| `PermissionError` | Нет прав | Закрой файл в Excel, запусти снова |

## 10. Режимы обучения

### Режим А: С учителем (ты сидишь рядом с другом)

**Как проходит урок:**
1. Ты открываешь модуль
2. Учитель объясняет что будем делать (2-3 минуты)
3. ТЫ (не учитель) копируешь промпт в Cline
4. ТЫ читаешь готовый код
5. Учитель объясняет непонятные моменты
6. ТЫ запускаешь код
7. Если ошибка — ТЫ копируешь её в Cline
8. Учитель помогает если застрял
9. В конце — ТЫ делаешь commit

**Роль учителя:** направлять и объяснять, НЕ делать за тебя.

### Режим B: Самостоятельно (один)

1. Открываешь модуль
2. Читаешь цель
3. Копируешь промпт
4. Запускаешь
5. Если непонятно — Cline объяснит
6. Если ошибка — Cline исправит
7. Отмечаешь чек-лист
8. Идёшь дальше

## 12. Как учителю передать курс другу

**Вариант 1: Через USB-флешку**
1. Скопировать папку `vibe-coding-course` на флешку
2. На компьютере друга скопировать на рабочий стол
3. Готово

**Вариант 2: Через GitHub**
1. Создать репозиторий на GitHub: `vibe-coding-course`
2. Выполнить команды:
```
git init
git add .
git commit -m "Курс Vibe Coding"
git remote add origin https://github.com/твой-логин/vibe-coding-course.git
git push -u origin main
```
3. Друг делает `git clone https://github.com/твой-логин/vibe-coding-course.git`

**Вариант 3: Через архив**
1. ПКМ по папке -> Отправить -> Сжатая ZIP-папка
2. Отправить архив через Telegram / почту / облако
3. Друг распаковывает на рабочий стол

## 13. Главные правила (выучи наизусть)

```
1. НИКОГДА не запускай код, который не прочитал
   (Zero Hallucination — железное правило)

2. Одна задача = один промпт
   (не проси ИИ сделать 10 дел сразу)

3. Если ошибка — прочитай её, покажи Cline, исправь
   (ошибки — это нормально, так учатся)

4. Делай git commit после каждого модуля
   (чтобы не потерять прогресс)

5. Читай код перед запуском
   (понимать важнее, чем копировать)

6. Не пропускай модули
   (каждый следующий опирается на предыдущий)

7. Вопросы — это хорошо
   (спрашивай Cline, спрашивай учителя)
```
