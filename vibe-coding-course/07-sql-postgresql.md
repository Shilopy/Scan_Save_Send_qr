## Что такое база данных

**База данных (БД)** — как Excel-файл с несколькими листами.
**Таблица** — как один лист в Excel.
**Строка** — одна запись (например, один заказ).
**Колонка** — одно поле (например, дата заказа).

## Что такое PostgreSQL

PostgreSQL (или просто Postgres) — это программа, которая хранит данные и умеет быстро их искать.
В отличие от Excel:
- Одновременно могут работать несколько человек
- Данные не теряются при сбое
- Можно писать сложные запросы через SQL
- Хранит миллионы строк без тормозов

## Что такое SQL

SQL — язык запросов к базе данных. На нём говорят "дай", "сохрани", "обнови", "удали".

**Основные команды SQL:**

| Команда | Что делает |
|---------|-----------|
| `CREATE TABLE` | Создать таблицу |
| `INSERT INTO` | Добавить строку |
| `SELECT` | Прочитать данные |
| `UPDATE` | Изменить данные |
| `DELETE` | Удалить данные |
| `WHERE` | Фильтр (условие) |
| `JOIN` | Объединить таблицы |
| `GROUP BY` | Сгруппировать |
| `ORDER BY` | Отсортировать |

## Шаг 3: Создание таблиц для сквозного проекта

Теперь создадим таблицы для нашего проекта "Система управления закупками".

**Промпт для Cline:**
```
Ты SQL-эксперт. Напиши SQL-запросы для PostgreSQL для создания таблиц в базе supply_db:

1. Таблица suppliers (поставщики):
   - id (автоинкремент, PRIMARY KEY)
   - name (название компании)
   - contact_person (контактное лицо)
   - phone (телефон)
   - email (email)
   - address (адрес)
   - rating (рейтинг 1-5)

2. Таблица materials (материалы/сырьё):
   - id (автоинкремент, PRIMARY KEY)
   - name (название)
   - unit (единица измерения: кг, шт, литр)
   - category (категория)
   - lead_time_days (срок поставки в днях)

3. Таблица supplier_prices (цены поставщиков):
   - id (автоинкремент, PRIMARY KEY)
   - supplier_id (ссылка на suppliers)
   - material_id (ссылка на materials)
   - price (цена)
   - valid_from (дата начала действия цены)
   - valid_until (дата окончания действия цены)

4. Таблица purchases (закупки):
   - id (автоинкремент, PRIMARY KEY)
   - supplier_id (ссылка на suppliers)
   - material_id (ссылка на materials)
   - quantity (количество)
   - price_per_unit (цена за единицу)
   - total_cost (quantity * price_per_unit)
   - purchase_date (дата закупки)
   - status (статус: ordered, received, cancelled)

5. Таблица sales_history (история продаж/спроса):
   - id (автоинкремент, PRIMARY KEY)
   - material_id (ссылка на materials)
   - quantity_sold (продано)
   - sale_date (дата продажи)

Добавь внешние ключи (FOREIGN KEY) везде где нужно.
Напиши комментарии к каждой таблице и колонке на русском.
```

**Выполни полученный SQL в psql.** Или скопируй весь SQL, вставь в psql и нажми Enter.

## Глоссарий SQL (шпаргалка)

```
SELECT              -- выбрать данные
  column1,          -- колонки
  AVG(column2)      -- среднее
FROM table          -- из таблицы
WHERE condition     -- где условие
GROUP BY column1    -- сгруппировать
HAVING condition    -- условие после группировки
ORDER BY column2    -- отсортировать
LIMIT 10            -- только 10 строк
;
```
