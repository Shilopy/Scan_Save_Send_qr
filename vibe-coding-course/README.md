# Vibe Coding для снабженца: с нуля до профи

## Что это?

Программа обучения **AI-assisted programming (vibe coding)** для человека с нулевым опытом программирования.
Фокус: **Python + SQL + бизнес-задачи снабжения**.

## Как проходить

1. Каждый модуль = одна учебная сессия (30 мин - 2 часа)
2. Сначала **прочитай модуль**, чтобы понять что делать
3. Потом **дай промпт из модуля в Cline** (или свой вариант)
4. **Запусти код**, проверь что работает
5. **Отметь выполнение** и переходи к следующему

## Сквозной проект

Через все модули красной нитью идёт проект **"Система управления закупками и запасами"**.
Каждый модуль добавляет к нему новый функционал:

1. Модуль 3: заготовка проекта
2. Модуль 7: таблицы БД (поставщики, материалы, закупки, продажи)
3. Модуль 9: Python подключается к БД
4. Модуль 10: бизнес-логика (прогноз, ABC-XYZ, MRP, поставщики)
5. Модуль 11: дашборды и отчёты

## Терминология

| Термин | Что значит |
|--------|-----------|
| Vibe coding | Написание кода через ИИ: ты говоришь что нужно, ИИ пишет код |
| Cline | AI-агент в VS Code, который пишет и редактирует код |
| Промпт (prompt) | Запрос, который ты отправляешь ИИ |
| CMD | Командная строка Windows |
| Python | Язык программирования для анализа данных |
| PostgreSQL / SQL | База данных и язык запросов к ней |
| Git | Система контроля версий |
| GitHub | Хранилище кода в интернете |

## Главные правила

1. **Zero Hallucination**: никогда не запускай код, который не прочитал и не понял
2. **Одна задача = один промпт**: не проси ИИ сделать 10 дел сразу
3. **Коммить после каждого рабочего изменения**: git add + git commit
4. **Ошибка - это нормально**: читай traceback, покажи ИИ, исправляй
5. **Понимать, а не копировать**: ИИ пишет код, ты понимаешь логику
