# Модуль 4: Промптинг — искусство общения с ИИ

**Время**: 2 часа
**Цель**: научиться составлять промпты, чтобы ИИ давал точный, рабочий код с первого раза

---

## Формула идеального промпта

```
Роль + Контекст + Задача + Детали + Формат вывода
```

### 1. Роль
Скажи ИИ, кем он должен быть.

_Примеры:_
- "Ты Senior Python-разработчик"
- "Ты опытный аналитик данных"
- "Ты эксперт по SQL"
- "Ты специалист по управлению цепями поставок"

### 2. Контекст
Дай информацию о проекте.

_Примеры:_
- "У меня есть CSV-файл sales.csv с колонками: date, product, quantity, price"
- "Я работаю над проектом supply_manager"
- "У меня PostgreSQL база данных с таблицей suppliers"

### 3. Задача
Сформулируй ЧТО нужно сделать. Конкретно.

_Плохо:_ "Сделай анализ"
_Хорошо:_ "Напиши функцию, которая считает общую сумму продаж по каждому товару за последний месяц"

### 4. Детали
Уточни нюансы.

_Примеры:_
- "Используй библиотеку pandas"
- "Обработай ошибку если файл не найден"
- "Данные могут быть с пропусками — заполни нулями"
- "Результат сохрани в CSV"

### 5. Формат вывода
Как ИИ должен вернуть результат.

_Примеры:_
- "Сохрани в файл analytics.py"
- "Обнови существующий файл utils.py"
- "Напиши SQL-запрос"
- "Покажи только изменения (diff)"

## Примеры промптов для снабженца

### Пример 1: Новичок
```
Ты Python-разработчик.
У меня есть CSV-файл sales.csv с колонками: date, product_name, quantity, price.
Напиши скрипт, который:
1. Загружает файл
2. Считает общую выручку (quantity * price) по каждому товару
3. Выводит таблицу: товар | выручка
4. Сортирует от большей выручки к меньшей
Сохрани в файл revenue_analysis.py
```

### Пример 2: Обработка ошибок в промпте
```
В том же revenue_analysis.py добавь обработку ошибок:
1. Если файл sales.csv не найден — выведи понятное сообщение
2. Если в данных есть пустые значения — пропусти их с предупреждением
3. Если price или quantity не число — сообщи в какой строке ошибка
```

### Пример 3: SQL запрос
```
Ты SQL-эксперт.
У меня PostgreSQL, таблица purchases с колонками:
id, supplier_id, material_name, quantity, price, purchase_date
Напиши запрос, который:
1. Показывает 10 последних закупок
2. С вычислением общей стоимости (quantity * price)
3. Отсортированных по дате от новых к старым
```

## Итеративный промптинг

Редко когда первый промпт даёт идеальный результат.
Нормально делать несколько итераций:

1. **Базовый промпт** — получаешь черновик
2. **Промпт-уточнение** — "добавь столбец с..."
3. **Промпт-доработка** — "перепиши так чтобы..."
4. **Промпт-рефакторинг** — "упрости код, убери дублирование"

**Пример:**
```
# Итерация 1
"Напиши функцию, которая загружает данные из Excel"

# Итерация 2
"Добавь проверку: если файла нет — создай пустой DataFrame"

# Итерация 3
"Переименуй функцию в load_sales_data() и добавь docstring"
```

## Как просить ИИ объяснить код

Иногда нужно понять чужой код (или свой старый).

**Промпт:**
```
Объясни этот код построчно:
[вставь код здесь]

Что делает каждая строка? Какие есть риски?
```

## Chain-of-Thought промптинг

Для сложных задач проси ИИ рассуждать по шагам:

```
Ты Senior Python-разработчик.
Мне нужно написать модуль прогнозирования спроса.
Перед тем как писать код, опиши план:
1. Какие данные нужны
2. Какой алгоритм использовать
3. Структура кода
4. Какие библиотеки

После моего одобрения напиши код.
```

## Анти-паттерны (как НЕ надо)

| Плохой промпт | Почему |
|--------------|--------|
| "Напиши код" | Слишком абстрактно |
| "Сделай как в прошлый раз" | ИИ не помнит, если не дать контекст |
| "Исправь всё" | Непонятно что исправлять |
| "Добавь фичу и перепиши структуру" | Две задачи в одном промпте |
| (просто вставить ошибку без пояснений) | Лучше: "Вот код, вот ошибка, исправь" |
