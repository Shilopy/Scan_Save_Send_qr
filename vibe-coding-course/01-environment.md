# Модуль 1: Окружение — установка и настройка

**Время**: 1.5 часа
**Цель**: установить всё необходимое и убедиться что работает

---

## Шаг 1: Основы — файлы, папки, диск C:

Объясни другу:
- **Файл** — как лист бумаги с текстом
- **Папка (директория)** — как папка для бумаг (скоросшиватель)
- **Диск C:** — как шкаф, в котором стоят папки
- **Рабочий стол** — самая верхняя папка, видна сразу после включения

## Шаг 2: Установка Python

1. Открыть браузер, перейти на [python.org](https://python.org)
2. Навести на Downloads -> Python 3.12+ (последняя версия)
3. Скачать установщик
4. **ВАЖНО**: при установке поставить галочку **"Add Python to PATH"**
5. Нажать Install Now
6. Дождаться завершения

**Проверка:**
- Нажать Win+R, ввести `cmd`, Enter
- В появившемся окне ввести:
```
python --version
```
- Должно показать: `Python 3.12.x` (цифры могут отличаться)

Если не показывает - Python не установился или не стоит галочка PATH.
Решение: переустановить, поставить галочку.

## Шаг 3: Установка VS Code

1. Перейти на [code.visualstudio.com](https://code.visualstudio.com)
2. Скачать установщик для Windows
3. Установить (все галочки можно оставить по умолчанию)
4. Запустить VS Code

## Шаг 4: Установка расширений VS Code

В VS Code слева есть панель с иконками.
Нажать иконку **Extensions** (квадратики, или Ctrl+Shift+X).
Установить:

1. **Python** (от Microsoft) — подсветка кода, запуск
2. **Cline** — AI-агент (иконка робота)

## Шаг 5: Настройка Cline

1. В левой панели VS Code появится иконка Cline (C字母 или робот)
2. Нажать на неё
3. Cline попросит API-провайдера:
   - Выбрать провайдера (например OpenAI, Anthropic, или OpenRouter)
   - Ввести API-ключ (если есть)
   - Если нет ключа - использовать OpenRouter (регистрация бесплатная, есть бесплатные модели)
4. Нажать "Done"

**Как получить OpenRouter ключ:**
1. Перейти на [openrouter.ai](https://openrouter.ai)
2. Зарегистрироваться (Google/GitHub)
3. Зайти в Keys, создать ключ
4. Скопировать ключ в Cline

## Шаг 6: CMD — командная строка

**Как открыть:**
1. Win+R -> ввести `cmd` -> Enter
2. Или в строке поиска Windows написать `cmd`

**Базовые команды (попробовать каждую):**

| Команда | Что делает |
|---------|-----------|
| `dir` | показать список файлов в текущей папке |
| `cd ..` | подняться на папку выше |
| `cd ИмяПапки` | зайти в папку |
| `mkdir НоваяПапка` | создать новую папку |
| `cls` | очистить экран |
| `python --version` | проверить версию Python |
| `pip --version` | проверить версию pip (установщик пакетов) |

## Шаг 7: Создание первой папки проекта

В CMD:
```
cd Desktop
mkdir my_first_project
cd my_first_project
```

Теперь ты в папке проекта на рабочем столе.

## Шаг 8: Первая строка кода

В VS Code:
1. File -> Open Folder -> выбрать `my_first_project` на рабочем столе
2. В VS Code слева появится панель с файлами
3. Открой Cline (иконка слева)
4. Напиши в чат:
   ```
   Создай файл main.py с кодом, который выводит "Привет, мир!"
   ```
5. Cline создаст файл

## Шаг 9: Установка DBeaver (для SQL-модулей позже)

1. Перейти на [dbeaver.io](https://dbeaver.io)
2. Скачать Community Edition (бесплатно)
3. Установить

## Шаг 10: Установка PostgreSQL (для SQL-модулей позже)

1. Перейти на [postgresql.org](https://www.postgresql.org/download/windows/)
2. Скачать установщик
3. При установке запомнить пароль для пользователя postgres
4. Запиши пароль в блокнот!

**Можно пока пропустить**, установить непосредственно перед Модулем 7.
