### 3. Когда НЕ использовать ИИ

- **Безопасность**: не давай ИИ пароли, ключи API, данные клиентов
- **Лицензии**: ИИ может сгенерировать код с чужой лицензией
- **Критичная логика**: проверяй расчёты вручную
- **Зависимости**: не устанавливай незнакомые библиотеки без проверки

### 4. Как ставить задачу ИИ для изучения

Вместо "напиши код для..." попробуй:

```
Объясни как работает pandas concat и merge.

Сравни SQL JOIN и pandas merge.
В чём разница?

Спроектируй структуру БД для управления складом.
Какие таблицы нужны? Какие связи?
```
