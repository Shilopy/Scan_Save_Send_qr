# Проект В: MRP — расчёт потребности в сырье

**Время**: 1 час
**Цель**: автоматизировать расчёт того, сколько и когда закупать сырья

---

## Бизнес-контекст

**MRP (Material Requirements Planning)** — это расчёт: "Если у нас есть план производства на месяц, сколько сырья нужно закупить и когда?"

Формула:
```
Потребность = План производства × Норма расхода
Заказ = Потребность - Остаток на складе + Страховой запас
```

## Шаг 1: Структура для MRP

**Промпт для Cline:**
```
В проекте supply_manager создай файл mrp.py.

Для MRP нужно знать:
1. Какие готовые продукты мы производим (products)
2. Из каких материалов состоит каждый продукт (bill_of_materials — спецификация)
3. Сколько продуктов нужно произвести (production_plan)
4. Текущие остатки материалов на складе (inventory)

Создай переменные (словари) с тестовыми данными:

products = {
    1: {"name": "Корпус металлический", "materials": {1: 2.5, 3: 0.1}},  # {material_id: норма расхода}
    2: {"name": "Крышка пластиковая", "materials": {2: 0.8, 4: 0.05}},
    3: {"name": "Ёмкость химическая", "materials": {1: 1.5, 2: 0.3, 3: 0.2}},
}

Где: 1=сталь_листовая, 2=полиэтилен, 3=краситель_красный, 4=растворитель

production_plan = {
    1: 100,   # нужно произвести 100 корпусов
    2: 200,   # 200 крышек
    3: 50,    # 50 ёмкостей
}

inventory = {
    1: 80,    # 80 кг стали на складе
    2: 50,    # 50 кг полиэтилена
    3: 5,     # 5 кг красителя
    4: 10,    # 10 л растворителя
}
```

## Шаг 2: Расчёт потребности

**Промпт для Cline:**
```
В mrp.py добавь функцию calculate_requirements(products, production_plan, inventory):
1. Для каждого материала рассчитывает:
   - total_required = сумма по всем продуктам (норма расхода × план производства)
   - to_order = total_required - inventory[материал] (если >0)
   - safety_stock = to_order * 0.2 (страховой запас 20%)
   - final_order = to_order + safety_stock
2. Выводит таблицу:
   Материал | ID | Требуется | На складе | Заказать | Страховой запас | Итого заказ
3. Возвращает словарь {material_id: final_order}
```

## Шаг 3: Расчёт дат заказа

**Промпт для Cline:**
```
В mrp.py добавь функцию calculate_order_dates(requirements, materials_data):
1. materials_data — словарь {id: {"name": ..., "lead_time_days": ...}}
2. Для каждого материала из requirements рассчитывает:
   - lead_time (срок поставки из materials_data или из таблицы materials в БД)
   - order_date = сегодня + 7 дней (время на обработку заказа)
   - delivery_date = order_date + lead_time
3. Выводит таблицу:
   Материал | Срок поставки (дней) | Дата заказа | Дата поставки
```

## Шаг 5: Отчёт MRP

**Промпт для Cline:**
```
В mrp.py добавь функцию export_mrp_report():
1. Вызывает полный цикл MRP-расчёта

   - "Потребность" — таблица из calculate_requirements
```
