# Модуль 0: Что такое Vibe Coding

**Время**: 30 минут
**Цель**: понять философию AI-assisted programming

---

## Что такое vibe coding?

Vibe coding (он же AI-assisted programming) - это подход, при котором **ты говоришь компьютеру на естественном языке, что нужно сделать, а ИИ пишет код**.

Ты не учишь синтаксис - ты учишься **ставить задачи и проверять результат**.

## Как это выглядит

1. Ты открываешь VS Code + Cline
2. Пишешь в чат Cline: *"Напиши Python скрипт, который читает Excel-файл с продажами и считает общую сумму"*
3. Cline пишет код
4. Ты читаешь код, запускаешь, проверяешь
5. Если нужно - просишь доделать

## Роли

| Кто | Что делает |
|-----|-----------|
| **Ты (человек)** | Ставишь задачу, проверяешь код, принимаешь решения |
| **Cline (ИИ)** | Пишет код, исправляет ошибки, объясняет |
| **Python** | Исполняет код |

## Железное правило

> **Zero Hallucination**: никогда не запускай код, который ты не прочитал и не понял хотя бы на 80%.

ИИ может ошибаться. Твоя работа - поймать эти ошибки до того, как код навредит.

## Демо: посмотри как это работает

Покажи другу свой экран с Cline:
1. Открой VS Code
2. Открой Cline (Ctrl+Shift+I или иконка в левой панели)
3. Напиши простой промпт: *"Напиши Python скрипт, который спрашивает имя пользователя и говорит 'Привет, {имя}!'"*
4. Нажми Enter
5. Покажи как Cline пишет код, создаёт файл
6. Запусти код через CMD
