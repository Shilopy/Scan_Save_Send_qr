# Проект А: Прогнозирование спроса

**Время**: 1 час
**Цель**: научиться предсказывать будущий спрос на основе истории продаж

---

## Бизнес-контекст

Снабженец должен знать, сколько сырья закупать в следующем месяце.
Если закупить мало — производство встанет. Если много — деньги заморожены в складе.
**Прогнозирование спроса** решает эту задачу.

## Шаг 1: Получаем данные о продажах

**Промпт для Cline:**
```
В проекте supply_manager создай файл forecast.py.

Напиши функцию load_sales_data():
1. Подключается к БД supply_db (через config.py)
2. Выполняет запрос:
   SELECT m.name, sh.quantity_sold, sh.sale_date
   FROM sales_history sh
   JOIN materials m ON sh.material_id = m.id
   ORDER BY sh.sale_date
3. Возвращает pandas DataFrame с колонками: name, quantity_sold, sale_date
```

## Шаг 2: Агрегация по месяцам

**Промпт для Cline:**
```
В forecast.py добавь функцию aggregate_monthly(df):
1. Принимает DataFrame из load_sales_data()
2. Преобразует sale_date в тип datetime
3. Группирует по месяцам (используй pandas Grouper)
4. Суммирует quantity_sold за каждый месяц
5. Возвращает DataFrame с колонками: month, total_sold

Добавь вызов этой функции для отладки.
```

## Шаг 3: Простой прогноз (среднее за 3 месяца)

**Промпт для Cline:**
```
В forecast.py добавь функцию simple_forecast(monthly_data, months_ahead=1):
1. Принимает агрегированные по месяцам данные
2. Берёт последние 3 месяца и считает среднее
3. Возвращает прогноз на months_ahead месяцев вперёд
4. Выводит в консоль: "Прогноз на следующий месяц: {значение} единиц"

Добавь в main.py вызов: из forecast → загрузить данные → построить прогноз
```

## Шаг 4: Прогноз через линейную регрессию

**Промпт для Cline:**
```
В forecast.py добавь функцию regression_forecast(monthly_data, months_ahead=3):
1. Использует sklearn.linear_model.LinearRegression
2. Обучает модель на исторических данных (месяц -> номер, спрос -> target)
3. Предсказывает на months_ahead месяцев вперёд
4. Возвращает список прогнозов
5. Выводит таблицу: Месяц | Прогноз

Добавь sklearn в requirements.txt
```

Установи: `pip install scikit-learn`

## Шаг 5: Визуализация прогноза

**Промпт для Cline:**
```
В forecast.py добавь функцию plot_forecast(monthly_data, forecast_values):
1. Использует matplotlib
2. Строит график:
   - Синяя линия — исторические данные
   - Красная пунктирная линия — прогноз
3. Подписи: ось X — месяцы, ось Y — количество
4. Заголовок: "Прогноз спроса"
5. Сохраняет график в файл forecast_chart.png

Добавь matplotlib в requirements.txt
```

Установи: `pip install matplotlib`

**Запусти:** `python main.py` и посмотри `forecast_chart.png`
